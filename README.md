# FleetDocs Pro — MVP Demo

Interactive mobile fleet management app demo built with HTML/CSS/JS.

## Live Demo
https://vish88git.github.io/fleetdocs-demo

## Features
- Fleet unit profiles with document status
- Driver profiles with expiry tracking  
- Push alert dashboard with urgency tiers
- Maintenance logs with odometer progress
- Document expiry engine with 30-day warnings

## Built for
Upwork bid demo — Mobile Fleet Management App for Trucking Company
